# 网页版个人作品集网站
> 前端轻量项目｜产品经理个人作品集落地

## 📌 项目背景
面向秋招求职场景，打造一个轻量化在线作品集网页。
目标是替代零散文档，统一展示个人简介、技能、项目案例、简历入口，方便面试官快速浏览我的产品实践，支持浏览器直接访问。

## 👤 我的角色
产品设计 + 前端实现
- 定义作品集页面信息架构、内容模块
- 设计页面布局、导航逻辑、浏览体验
- 使用 HTML + CSS 完成页面开发
- 后续计划：部署 GitHub Pages，生成公开访问链接

## 🧩 页面模块规划
1. 首页Banner：自我介绍 + 求职定位
2. 技能模块：产品工具、业务能力标签
3. 项目卡片区：展示各个产品项目，点击可展开详情
4. 简历与联系区：在线简历链接、邮箱

## ✅ 技术栈
HTML5 / CSS3，无复杂框架，轻量化、加载快，适配电脑端浏览。
